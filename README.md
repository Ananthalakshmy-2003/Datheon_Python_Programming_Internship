# Datheon Python Programming Internship

## About
This repository contains five Python projects developed as part of the Datheon Python Programming Internship. These projects demonstrate practical Python programming skills, problem-solving, file handling, data management, and Object-Oriented Programming.

## Projects

### 1. Hangman Game
A word-guessing game in which users guess letters to identify a randomly selected word before running out of attempts.

**Concepts:** Python basics, loops, conditional statements, strings, sets, random module.

### 2. Investment Portfolio Tracker
A program that tracks stock investments and calculates investment value, current value, profit or loss, and percentage returns. It exports summaries to a CSV file.

**Concepts:** Dictionaries, calculations, CSV file handling.

### 3. Automatic File Organizer
A utility that automatically organizes files into folders based on their file extensions.

**Concepts:** OS module, pathlib, shutil, file handling, exception handling.

### 4. Customer Support Chatbot
A rule-based chatbot that responds to common customer queries such as greetings, delivery information, product details, and return policies.

**Concepts:** Functions, dictionaries, regular expressions, conditional statements.

### 5. Smart Inventory System
An inventory management application that manages books, magazines, and digital media. It supports adding, searching, borrowing, returning, fee calculation, and audit reports.

**Concepts:** Object-Oriented Programming, abstraction, encapsulation, inheritance, polymorphism, properties, and dunder methods.

## Technologies Used
- Python 3
- Visual Studio Code
- CSV file handling
- Python standard libraries
- Object-Oriented Programming

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the required project folder in VS Code.
4. Open the terminal.
5. Run the corresponding Python file.

Example:

```bash
cd Hangman_Game
python hangman.py
```

Refer to each project's README.md for its individual instructions.
